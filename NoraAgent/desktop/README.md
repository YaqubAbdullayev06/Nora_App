# Nora Desktop Agent

An AI assistant that lives in your system tray and controls your computer.

## Features
- **Hotkey**: Press `Ctrl+Shift+N` to summon Nora anywhere
- **AI Chat**: Talk to Nora (powered by Ollama local LLM)
- **File Search**: Find any file on your computer instantly
- **App Launcher**: Open any app with a voice command
- **System Control**: Run commands, open folders, search web
- **Works Offline**: Uses local Ollama, no internet needed

## Setup
```bash
pip install -r requirements.txt
python nora_agent.py
```

## How It Works
1. Nora sits in your system tray (bottom right corner)
2. Press `Ctrl+Shift+N` from anywhere
3. A floating AI window appears
4. Type or speak to Nora
5. Nora can search files, open apps, answer questions, and more
